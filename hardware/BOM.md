# Capture stack — iPhone Pro Max

Buy list: **[PARTS.md](PARTS.md)**. Tests: **[../docs/TESTING_PLAN.md](../docs/TESTING_PLAN.md)**.

Pi / MPU-6050 / Pi camera kits are **retired**. Do not buy them for this product.

## What the phone already is

| Sensor | Role |
|---|---|
| LiDAR (12 Pro and newer) | Mesh of pavement; stored as ASCII PLY; voxel-merged across people |
| Camera | LLM / optional YOLO classes with LA weights |
| Gyroscope | Pose quality — drop scans that were whipped around |
| Accelerometer | Roughness / impact |
| Magnetometer + true heading | Align opposite-direction walks of the same cell |
| GPS | Scene ID (~20 m cell) |
| Barometer | Weak relative height (overpass), clipped |
| ARKit tracking state | Trust / no-trust |

## Do not buy

Pi Zero loggers, HC-SR04 “NDT”, extra drones, GPR for this version.
